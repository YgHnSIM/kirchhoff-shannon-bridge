CURRICULUM.md에 고정된 순서입니다. 복귀 학습자는 foundation을 끝까지, 이미 회로·정보에 익숙하면 Bridge의 \(S \neq H\)부터 건너뛸 수도 있습니다 — 다만 기초 문서의 「한계」 절은 한 번 훑는 것을 권합니다.

Phase A · 기초

Foundation

측정·추상화·수학·역사·물리 복습. 오래 쉰 학습자의 재진입로.

  1. 이 코스를 읽는 법「두 엔트로피」의 읽기 규칙, 문서 구조, 수식·용어 약속, 학습 리듬을 안내한다.
  2. 측정과 추상화물리량·정보량을 재는 행위와, 그 결과를 기호·법칙으로 추상화하는 과정을 정리한다.
  3. 수학 입문 복습확률·로그·급수·선형대수의 최소 도구를, 오래 쉰 학습자가 다시 잡도록 친절히 복습한다.
  4. 역사적 프레임Kirchhoff에서 Planck로, Shannon의 1948년으로 이어지는 두 줄기의 역사적 질문을 배치한다.
  5. 물리학 복습 — 전류·전압·저항·에너지·파동·빛오래 쉰 학습자를 위해 회로량의 정의와 옴의 법칙, 에너지, 파동·빛의 최소 골격을 두껍게 복습한다.
  6. 학습 복귀 가이드오래 학습을 쉬었던 사람을 위한 선수 맵, 자기진단, 추천 경로, 리듬·함정을 안내한다.

Phase B · 키르히호프

Kirchhoff

회로 이전사 → KCL/KVL → 회로망 → 분광·복사 → 플랑크 직전 → 생애.

  1. 회로 이전 — 옴의 법칙과 공예로서의 전기옴의 법칙 시대의 회로 공예와 키르히호프가 푼 문제 — 분기·다루프 회로의 체계적 해석.
  2. KCL과 KVL — 가정·방법·예제집중정수·준정적 가정 아래 KCL/KVL을 정식화하고, 노드·루프법과 수치 예제, 흔한 오개념을 다룬다.
  3. 회로망 — 다단자·직렬병렬·세지 말아야 할 것직렬·병렬 직관의 유효 범위와 다단자망, 키르히호프의 네트워크·나무 계수와의 역사적 연결을 다룬다.
  4. 분광학 — 프라운호퍼선에서 원소 지문까지프라운호퍼선, 분젠–키르히호프 분광, 방출·흡수 대응, 세슘·루비듐 발견의 맥락.
  5. 열복사 법칙 — 방출·흡수·흑체키르히호프의 열복사 법칙(방출능=흡수능), 흑체 정의의 유래, 보편함수로의 귀결을 다룬다.
  6. 흑체 스펙트럼의 열린 문제 — 플랑크를 향하여키르히호프가 남긴 B(λ,T) 결정 문제, 빈·레일리–진스, 고전적 곤경, 플랑크 식으로의 진입. QFT를 가장하지 않는다.
  7. 키르히호프의 생애 — 연구와 교차한 시간1824–1887, 쾨니히스베르크·하이델베르크·장애·베를린 석좌를 연구 연대기와 엮어 학술 톤으로 정리한다.

Phase C · 섀넌

Shannon

불 대수 계전기 → 정보 → 엔트로피 → 원천·채널 → 비밀성 → 생애.

  1. 불 대수와 계전기 — 1937년 석사논문Shannon의 1937년 석사논문이 불 대수와 계전기 회로를 대응시켜 디지털 설계의 언어를 연다.
  2. 정보란 무엇인가 — 의미 없이 양만Shannon 정보의 정의는 의미·진리가 아니라 불확실성·선택·놀라움의 측도이며, 비트는 그 단위다.
  3. 엔트로피 H — 평균 불확실성H(X)는 자기정보의 평균이며, 결합·조건부 엔트로피와 연쇄법칙, 이진 엔트로피 H(p)를 엄밀히 둔다.
  4. 소스 부호화 — 압축의 하한소스 부호화 정리의 직관 — 전형 집합과 엔트로피율 — 으로 무손실 압축의 근본 한계를 이해한다.
  5. 채널 용량 — 잡음 속의 상한잡음 채널의 상호정보 최대값으로 용량을 정의하고, BSC 공식과 Shannon 한계의 뜻을 고정한다.
  6. 비밀의 정보이론 — 1949Communication Theory of Secrecy Systems(1949)의 정보이론적 비밀·완전 비밀 개념과 Vernam/일회용 패드와의 개념적 연결. 공격 절차는 다루지 않는다.
  7. Shannon의 생애 — 1916–2001Claude Shannon의 생애와 주요 활동 — Michigan, MIT, Bell Labs, 전시 연구, 취미와 유니사이클 — 을 학술적 톤으로 정리한다.

Phase D · 다리

Bridge

보존 은유 → 두 엔트로피(S≠H) → 흑체에서 비트 → 생애 비교 → 더 읽기.

  1. 보존의 은유 — 전류와 정보키르히호프 전류법칙(KCL)의 엄밀한 보존과, 정보·채널 용량에서 「보존」이라고 말하는 것의 차이를 은유와 정의의 경계에서 정리한다.
  2. 두 엔트로피 — S와 H는 같은 물리량이 아니다열역학 엔트로피 S와 섀넌 엔트로피 H의 형식적 유비와 존재론적 차이를 명시하고, 동일시 오개념에 경고한다.
  3. 흑체에서 비트로 — 간접적인 개념사키르히호프의 흑체에서 플랑크·통계역학 문화를 거쳐 나이퀴스트·하틀리·섀넌의 통신·정보에 이르는 길을, 직접 계보가 아닌 간접 링크로 정직하게 서술한다.
  4. 두 생애 — 회로·현상·이중의 걸작키르히호프와 섀넌의 생애·업적을 세 축(회로의 수학화, 모호의 측정 가능화, 초기 서명 결과와 후기 제2의 걸작)으로 비교하고 시대차를 명시한다.
  5. 더 읽기 — 원논문·교과서·백과Bridge 트랙 이후를 위한 큐레이션 서지 — 1차 문헌, 표준 교과서, 양자·열역학 입문, 온라인 백과. 장문 복제 없이 길잡이만.
