# 학습 복귀 가이드

## 정의 — 「복귀」가 의미하는 것

이 문서에서 **학습 복귀(coming back)** 란, 정규 교육이 끝난 뒤 수년~수십 년이 지난 사람이 **다시 기호·수식·실험 서술을 다루는 상태**로 돌아오는 과정을 말한다. 지능의 문제가 아니라 **근육과 지도**의 문제다.

목표 상태는 “모든 것을 다시 전공한다”가 아니라, **「두 엔트로피」 Phase B–D를 따라갈 최소 체력**을 회복하는 것이다.

## 왜 별도의 가이드가 있는가

- foundation 00–04를 순서대로 읽어도, 사람마다 **빈칸의 위치**가 다르다.
- 어떤 이는 회로는 선명한데 확률이 흐리고, 어떤 이는 그 반대다.
- “처음부터 다 다시”는 중도 포기율만 높인다. **진단 → 최소 경로 → 본진**이 필요하다.

## 역사·동기 (학습자로서의 동기)

Kirchhoff도 Shannon도 “교양 에세이”가 아니라 **당시의 단단한 문제**에 응답했다. 복귀 학습자도 마찬가지로, 막연한 교양 갈증보다 **한 줄의 질문**(예: “\(S\)와 \(H\)는 왜 다른가?”, “흑체에서 비트까지 무엇이 옮겨졌는가?”)을 품으면 지속된다. 이 코스는 그 질문을 위해 Phase A를 두껍게 깔아 두었다.

## 선수 맵 (개념 의존)

```
측정·추상화 (01)
        │
        ▼
수학 최소 (02: 로그·확률·급수·연립)
        │
        ▼
역사 프레임 (03) ──┐
        │          │
        ▼          │
물리 복습 (04)     │
        │          │
        ▼          ▼
   ┌────┴────┐  동기 유지
   ▼         ▼
kirchhoff/  shannon/
   └────┬────┘
        ▼
     bridge/   (S ≠ H 명시)
```

**필수에 가까운 것**

| 가고 싶은 곳 | 먼저 손에 익힐 것 |
|--------------|-------------------|
| kirchhoff/ KCL·KVL | 04의 전류·전압·저항, 02의 연립 |
| kirchhoff/ 분광·복사 | 04의 파동·빛, 02의 급수·적분 감각 |
| shannon/ 엔트로피 | 02의 확률·로그 전부 |
| shannon/ 채널 용량 | \(H\), 조건부, \(I(X;Y)\) 이름과 식 |
| bridge/ 두 엔트로피 | 양 트랙의 중반 + “\(S\neq H\)” 경고 |

## 자기진단 (10분)

각 항목에 O / △ / X를 표시하라.

1. \(V=IR\)에서 \(V\)가 **두 점**의 양임을 설명할 수 있다.
2. 직렬·병렬 등가저항을  deriv 없이라도 맞게 쓸 수 있다.
3. \(\log(ab)=\log a+\log b\)를 증명 없이 쓰며 밑 변환을 한다.
4. \(p\)가 확률분포일 때 \(\sum p=1\), \(H=-\sum p\log p\)를 계산할 수 있다.
5. “파동의 진동수와 파장”을 한 그림으로 설명할 수 있다.
6. Shannon 1948이 **의미**를 제쳐 두었다는 문장을 이해하고 있다.
7. 열역학 \(S\)와 정보 \(H\)를 같다고 말하지 않을 자신이 있다.

**판독**

- 1–2가 △/X → 04를 천천히, 연습까지.
- 3–4가 △/X → 02를 두 번. shannon 진입 전 필수.
- 5가 △/X → 04 후반 + 시각 자료.
- 6–7이 X → 00, 03, 그리고 나중에 b-02를 예약.

## 추천 경로

### 경로 α — 「완전 복귀」(권장 기본)

`00 → 01 → 02 → 03 → 04 → 05(이 문서 재확인) → k-01 → …`  
병행: 주 1회 glossary에서 용어 5개씩.

### 경로 β — 「회로가 아직 선명」

`00 → 01 → 02(확률·로그 집중) → 03 → 04는 파동·빛만 → shannon 쪽으로 먼저` 도 가능.  
다만 **bridge 전에** kirchhoff의 복사 쪽(k-04~k-06)은 반드시 건넌다.

### 경로 γ — 「확률·정보는 익숙, 물리만 공백」

`00 → 03 → 04 전부 → 02는 급수·행렬만 → kirchhoff 우선`.  
shannon은 복습 속도로 훑고 bridge에서 만난다.

### 경로 δ — 「시간이 절대적으로 부족」

최소: `00 → 02(확률·로그) → 04(전류·전압) → 03 → bridge의 b-02만 먼저 예고 독해 금지, 대신 glossary의 S/H 항목`.  
이후 빈칸을 역으로 채운다. **얇은 성공 후 두껍게**가 포기보다 낫다.

## 리듬과 환경

- **한 문서 = 하루 또는 이틀.** foundation은 1500–3500자(+) 규모이나, 연습까지가 한 세트다.
- 수식은 **손으로 한 줄 따라 쓰기**. 눈만 통과하면 복귀가 안 된다.
- 막히면 “나는 머리가 둔하다”가 아니라 **선수 맵의 어느 칸인지**를 적는다.
- 주 단위로 “이번 주에 되살린 용어 3개”만 적어도 진척이 보인다.

## 흔한 함정

1. **교양 유튜브만 보고 본문 수식을 건너뛰기** — 이 코스는 교양 금지를 계약한다.
2. **\(S=H\)로 빨리 통일하고 싶어 하기** — Bridge까지 미뤄라.
3. **원논문 PDF를 처음부터 통독** — 먼저 코스 본문, 그다음 짧은 구절·이차 문헌.
4. **모든 연습의 완벽 해답** — 스케치면 충분. 막힌 문항만 재방문.

## 수식 — 「복귀 체크」 한 장

다음을 빈칸 없이 다시 쓸 수 있으면 Phase A 졸업에 가깝다.

\[
V=IR,\quad P=VI,\quad
H(X)=-\sum_x p(x)\log p(x),\quad
\sum_{\mathrm{node}} I=0,\quad
\sum_{\mathrm{loop}} V=0
\]

그리고 문장: **「열역학 엔트로피 \(S\)와 섀넌 엔트로피 \(H\)는 같은 양이 아니다.」**
